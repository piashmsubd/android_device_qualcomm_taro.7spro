A fully functional TWRP device tree for the **RedMagic 7S Pro (NX709S)** with Snapdragon 8+ Gen 1 (taro) platform.

## 🔥 Key Highlights

- ✅ **Dedicated Recovery Partition** - Virtual A/B with separate recovery (uncommon!)
- ✅ **Full ro2rw Support** - Mount system as read-write, edit files freely
- ✅ **FBE Decryption** - Hardware-accelerated encryption with metadata support
- ✅ **Complete Partition Access** - All logical partitions accessible
- ✅ **Automated Builds** - GitHub Actions powered CI/CD

## 📝 Changelog - What Was Fixed

### 🔨 Major Fixes & Changes

#### 1. **BoardConfig.mk** - Core Configuration
| Change | Before | After | Reason |
|:-------|:-------|:------|:-------|
| **Virtual A/B** | Not enabled | `ENABLE_VIRTUAL_AB := true` | Required for Android 12+ devices with dynamic partitions |
| **A/B Partitions** | Missing boot/vendor_boot | Added `boot`, `vendor_boot`, `vbmeta_system` | Complete A/B partition list |
| **Recovery Mode** | Standard recovery | `TARGET_NO_RECOVERY := true` | Recovery is embedded in boot image (A/B requirement) |
| **Boot Header** | Already v4 | Kept version 4 | Correct for Snapdragon 8+ Gen 1 |
| **Kernel Offsets** | Missing | Added base, ramdisk, tags, DTB offsets | Required for proper boot image creation |
| **DTB Configuration** | Missing | `BOARD_INCLUDE_DTB_IN_BOOTIMG := true` | Device tree blob must be in boot image |

## 🔧 Building TWRP

### Method 1: GitHub Actions (Recommended - Automated)

1. **Fork this repository** (if not already done)

2. **Go to Actions tab** in your GitHub repository

3. **Select** "Build TWRP for RedMagic 7S Pro" workflow

4. **Click** "Run workflow" button

5. **Configure build options**:
   - **TWRP Manifest Branch**: `twrp-12.1` (recommended) or `twrp-11`
   - **Device Tree Branch**: Use your current branch name
   - **Build Target**: `recoveryimage` (default)

6. **Wait** for build to complete (~1-2 hours)

7. **Download** recovery.img from:
   - **Artifacts** section (temporary, 90 days)
   - **Releases** section (permanent)

**Build URL**: https://github.com/piashmsubd/android_device_qualcomm_taro.7spro/actions

---

### Method 2: Local Build (Manual)

#### Prerequisites
```bash
# Install dependencies (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y \
  git aria2 curl wget rsync zip unzip \
  build-essential gcc g++ clang cmake ninja-build \
  python3 python-is-python3 bc bison flex \
  libssl-dev libncurses5 libxml2-utils \
  schedtool libtinfo5 repo ccache \
  openjdk-11-jdk android-sdk-platform-tools
```

#### Build Steps
```bash
# 1. Create working directory
mkdir -p ~/twrp
cd ~/twrp

# 2. Initialize TWRP minimal manifest
repo init --depth=1 -u https://github.com/minimal-manifest-twrp/platform_manifest_twrp_aosp.git -b twrp-12.1

# 3. Sync repository
repo sync -c --no-clone-bundle --optimized-fetch --prune --force-sync -j$(nproc --all)

# 4. Clone device tree
git clone https://github.com/piashmsubd/android_device_qualcomm_taro.7spro.git -b NX709S-user-12-SKQ1.220502.001-eng.nubia.20241204.170923-release-keys device/qualcomm/taro

# 5. Setup environment
export ALLOW_MISSING_DEPENDENCIES=true
export LC_ALL=C
source build/envsetup.sh

# 6. Select device
lunch omni_taro-eng

# 7. Build TWRP
mka recoveryimage -j$(nproc --all)

# 8. Output location
# Recovery image: out/target/product/taro/recovery.img
```

#### Build Time
- **GitHub Actions**: ~1-2 hours (automated)
- **Local Build** (8-core CPU): ~1-3 hours
- **ccache enabled**: Subsequent builds ~30-45 minutes

## 📲 Installation Guide

### Prerequisites
- **Unlocked bootloader** (required!)
- **ADB and Fastboot** tools installed
- **USB debugging** enabled on device

### Step 1: Download TWRP
Download the latest `recovery.img` from:
- **GitHub Releases**: https://github.com/piashmsubd/android_device_qualcomm_taro.7spro/releases
- **Build Artifacts**: GitHub Actions → Latest successful build

### Important Note: Partition Layout
**RedMagic 7S Pro has SEPARATE boot and recovery partitions:**
- `/dev/block/bootdevice/by-name/boot` - Android system boot
- `/dev/block/bootdevice/by-name/recovery` - TWRP recovery (separate!)

This is **Virtual A/B with dedicated recovery** - uncommon but correct for this device.

### Step 2: Boot to Fastboot Mode
```bash
# Method 1: Via ADB
adb reboot bootloader

# Method 2: Manual
# Power off device → Hold Volume Down + Power until fastboot appears
```

### Step 3: Flash TWRP
```bash
# Flash to recovery partition (IMPORTANT: Use 'recovery', NOT 'boot')
fastboot flash recovery TWRP-NX709S-*.img

# For A/B devices, flash to both slots
fastboot flash recovery_a TWRP-NX709S-*.img
fastboot flash recovery_b TWRP-NX709S-*.img

# Verify flash was successful
fastboot getvar current-slot
```

**Note**: This device has a **dedicated recovery partition**. Flash to `recovery`, NOT `boot`!

### Step 4: Boot into TWRP
```bash
# Method 1: Via Fastboot
fastboot reboot recovery

# Method 2: Manual
# Hold Volume Up + Power until TWRP logo appears
```

### Step 5: First Boot Setup
1. **Decrypt Data** (if prompted):
   - Enter your PIN/Password
   - TWRP will decrypt `/data` partition

2. **Allow Modifications** (if prompted):
   - Swipe to allow system modifications
   - Required for full TWRP functionality

3. **Verify Mounts**:
   - Go to **Mount** menu
   - Check that System, Vendor, Data are mounted

## 🛠️ Usage & Features

### Backup & Restore
1. **Create Backup**:
   - Tap **Backup**
   - Select partitions (Boot, System, Data, Vendor)
   - Swipe to backup

2. **Restore Backup**:
   - Tap **Restore**
   - Select backup folder
   - Choose partitions to restore
   - Swipe to restore

### Install Custom ROM
1. **Wipe Data** (optional but recommended):
   - Tap **Wipe** → **Advanced Wipe**
   - Select: Dalvik/ART Cache, Cache, System, Data
   - Swipe to wipe

2. **Install ROM**:
   - Tap **Install**
   - Navigate to ROM zip file
   - Swipe to flash
   - Flash GApps/Magisk if needed

3. **Reboot**:
   - Tap **Reboot** → **System**

### Install Magisk
1. **Download** latest Magisk APK
2. **Rename** to `Magisk.zip`
3. **Flash** via TWRP Install menu
4. **Reboot** to system

### Format Data (Remove Encryption)
1. **Wipe** → **Format Data**
2. Type `yes` to confirm
3. **Warning**: This will erase all internal storage!

## 🐛 Troubleshooting

### Issue: "Unable to mount /data"
**Solution**:
- This is normal if data is encrypted
- Enter your PIN/password when prompted
- If decryption fails, you may need to format data

### Issue: "No OS Installed"
**Solution**:
- This appears after wiping system
- Flash a ROM immediately
- Or restore from backup

### Issue: Touch not working
**Solution**:
- Reboot to recovery again
- Check if touch driver is loaded in TWRP logs
- May need to flash different TWRP build

### Issue: MTP not working
**Solution**:
- Enable MTP in **Mount** menu
- Check USB cable connection
- Try different USB port on PC
- Install appropriate USB drivers on Windows

### Issue: Backup fails with "Not enough space"
**Solution**:
- Free up space in `/data`
- Use external SD card for backups
- Enable compression in backup settings

### Issue: Cannot mount system as read-write (ro2rw)
**Solution**:
- ✅ **Already Fixed** in this device tree!
- System mount support is built-in
- Go to **Mount** menu
- Check "Mount system partition read-write"
- You can now edit system files

### Issue: System modifications not persisting
**Solution**:
- Make sure you enabled "Mount system partition read-write"
- Disable dm-verity if prompted
- Some ROMs have system-as-root which may need special handling
- Use TWRP File Manager to verify changes were saved
